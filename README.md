# yahtzee

终端 Yahtzee 骰子游戏:掷 5 颗骰子、最多重掷 2 次,13 个计分项打满一局。

## 玩法

```bash
python -m yahtzee              # 交互游玩
python -m yahtzee --auto       # 自动演示一局
python -m yahtzee --auto --seed 42
```

每轮掷 5 颗骰子,可重掷 2 次(输入要保留的骰子序号,如 `1 3 5`;直接回车全部重掷),
然后从剩余计分项里选一项记分。

## 计分规则

- 上半区:一点~六点,按该点数总和记分;上半区合计 ≥63 分奖励 35 分
- 下半区:三条(总和)、四条(总和)、葫芦 25、小顺 30、大顺 40、Yahtzee 50、机会(总和)

## 已知局限

- 单人模式,无多人对战、无排行榜
- 交互模式需要终端(tty);管道输入请用 `--auto`
- 重掷策略(`--auto`)是简单启发式(保留最多的点数),不是最优策略
- 无存档,退出即清零
